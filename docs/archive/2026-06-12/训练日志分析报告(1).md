## 三、关键发现与深度解读

### 🔴 问题 1：所有模型均存在严重过拟合（核心瓶颈）

**每个实验**在 best epoch 之后验证集性能都持续下降：

```
cls2w125:        0.6890 → 0.6444  (↓ 4.5% | Gap 变化 0.082)
cls011_cls2w15:  0.6864 → 0.6688  (↓ 1.8% | Gap 变化 0.053)  ← 最抗过拟合
cls2w16:         0.6766 → 0.6640  (↓ 1.3% | Gap 变化 0.050)
cls2w15_dice035: 0.6788 → 0.6258  (↓ 5.3% | Gap 变化 0.093)
cls2w135:        0.6572 → 0.6043  (↓ 5.3% | Gap 变化 0.156)
cls2w15_lr25e5:  0.6692 → 0.6233  (↓ 4.6% | Gap 变化 0.092)  ← 过拟合最严重
```

**Train-Val Dice Gap 演变趋势**（负值 = Val > Train，泛化良好；正值 = 过拟合）：

```
Best Epoch:         所有实验 gap < 0（Val > Train）→ 模型泛化良好 ✅
Final Epoch:        所有实验 gap > 0（Train > Val）→ 模型已过拟合 ❌
```

**根源分析**：
1. **Early Stopping patience=25 过大** — best epoch 后允许继续训练 25 个 epoch，模型在 plateau 后长时间无效训练
2. **Weight Decay 过低（0.0002）** — 正则化力度不足，模型容量（7.25M）相对数据量偏高
3. **无 Dropout** — 模型配置中未启用 Dropout 层，缺乏隐式正则化
4. **数据增强上限保守** — curriculum_max_aug_level=0.4 可能在后期不足

### 🟢 发现 2：Class Weight 1.25 是最优值

cls2w125（class 2 weight=1.25）以**最简单的权重配置**获得最高 Dice。继续增大 class 2 权重反而导致性能下降：

```
class_2_weight: 1.25 → Dice 0.689 ✅ 最佳峰值
class_2_weight: 1.35 → Dice 0.657 ❌ 最差（下降 3.2%）
class_2_weight: 1.50 → Dice 0.686
class_2_weight: 1.60 → Dice 0.677
```

**解读**：Class 2 确实需要上采样（说明该类样本少/难学），但过度上采样会：
- 引入重复样本的噪声
- 破坏原始数据分布
- 导致该类在验证集上反而泛化更差

### 🟢 发现 3：cls011_cls2w15 综合表现最优（推荐基线）

虽然 cls2w125 峰值略高（+0.0026），但 **cls011_cls2w15** 在以下方面更优：

| 维度 | cls2w125 | cls011_cls2w15 | 优势 |
|---|---|---|---|
| Best Val Dice | 0.6890 | 0.6864 | cls2w125 微弱领先 |
| **Final Val Dice** | 0.6444 | **0.6688** | cls011 领先 2.4% ✅ |
| **Gap 稳定性** | ±0.082 | **±0.053** | cls011 更稳定 ✅ |
| Best → Final 衰减 | -4.5% | **-1.8%** | cls011 衰减最小 ✅ |

**同时提升 class 0 和 class 1 的权重（1.0→1.1）起到了隐式正则化作用**，让模型不仅关注 class 2，也平衡了对其他类的学习。

### 🟡 发现 4：提高 LR 加速收敛但严重加剧过拟合

lr=2.5e-5 的实验特征：
- ✅ Best epoch 最早（59 vs 67）— 收敛更快
- ✅ 峰值 train dice 最高（0.709）— 训练集拟合更好
- ❌ Train-Val gap 恶化最严重（-0.006 → +0.086，变化 0.092）
- ❌ Final val dice 最低之一（0.6233）

**结论**：更高学习率使模型更快穿越损失曲面到达局部最优，但也更快进入过拟合区域。当前 2e-5 更合理。

### 🟡 发现 5：提高 Dice 权重无明显收益

dice_weight=0.35 + bce_weight=0.65 vs dice_weight=0.3 + bce_weight=0.7：

- 峰值 Dice：0.6788 vs 0.6864（**下降 0.76%**）
- Final gap：+0.065 vs +0.024（**过拟合更严重**）
- Dice 权重提高反而削弱了 BCE 的分类校准能力

### 🟡 发现 6：数据增强课程学习正常生效

所有实验的数据增强课程学习均按计划推进：
- 增强起始 epoch：40
- 最终增强等级：0.4（达到预设上限）
- 最终增强参数一致：brightness_limit=0.12, rotation_limit=21°, zoom_limit=0.058, noise_std=0.006

**未触发自适应调整**（`final_adaptive_next_level=null`），说明预设的固定余弦 schedule 在 0.4 水平上已经饱和，模型可能从更强的增强中受益。
